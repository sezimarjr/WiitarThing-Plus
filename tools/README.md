# Tools

Helper scripts shipped next to `WiitarThing.exe` in the release (messages are in Portuguese).

| Script | What it does |
| --- | --- |
| `TESTAR_CONTROLE.bat` / `testar_controle.ps1` | Live view of the virtual Xbox controller: frets, strum, Select/Start, whammy and tilt. |
| `MONITORAR_SESSAO.bat` | Starts WiitarThing-Plus with `--monitor`, or turns the monitor on in the running instance. |
| `RESUMO_MONITOR.bat` / `resumo_monitor.ps1` | Summarizes the latest session in the `monitor` folder (Bluetooth timing and per-fret dropouts). |
